## 13. Scripts, datatables, registration
- **S30 client perm paks carry the map's CLIENT scripts as wraps** and they override loose files; census their natives against S21 before shipping (section 15).
  Census = every identifier/method the wraps call vs S21 script defs + NUL-delimited strings in r5apex_dx12.exe
  (mu5: `<WORK>\mu5_natives\census.py`). Done for World's Edge: `SetMapSetting_WideBloomAmount` /
  `SetMapSetting_BloomCutoffOverride` are client.dll natives (unify `map_bloom_settings.cpp`), and
  `ForcedSpawn_SetMapViewValues` is a CLIENT script fn in `sh_forced_spawning.nut`. S30-only `#DES_ZONE_*` tokens:
  hash with `string_to_guid`, take strings per language from S30 `localization_<lang>.rpak` (rsx-kral `--exporttypes locl`),
  add to catalog/entries AND insert into the tables surgically (a full `loc_safe_merge.py merge` drops
  translations other sessions hand-put in the tables).
- The engine loads `tools/levels/<map>.rson` (dedi log `Loading script list`); without it there is no map
  init at all. Build it from the twin's: SERVER `mp/levels/<map>.nut` (+ `mp/_lasermesh.gnut`), CLIENT
  `mp/levels/cl_<map>.nut` (+ `mp/cl_lasermesh.gnut`), SHARED `mp/levels/mp_rr_<family>_common.nut`. Copy the
  twin's level .nut files, point `MapZones_RegisterDataTable` at `datatable/map_zones/zones_<map>.rpak`
  (S30 map pak dtbl, columns triggerName/zoneName/miniMapName/zoneGroup/statsRef match S21), and check every
  `GetEntByScriptName(...)` the scripts use exists in the map's ents (a missing single-entity lookup kills the
  host; `GetEntArrayByScriptName` misses are harmless). mu5: s21-scripts `54d9d518`.
- The zones dtbl must be in BOTH the client pak and the dedi rpak (section 5).
- Shared tables: `MAP_DISPLAY_NAMES` (sh_playlists.gnut), `GAMEMODE_INSTALLED_MAPS` (ui/lobby_panel_gamemodes.nut),
  `GetPodiumBackgroundSkinFromMapName` (sh_gamemode_survival.nut, twin's background). Also
  `platform\r5f_map_names.txt`, the playlist maps block (`playlists_r5_patch.txt`), localization
  `"<map>" "<name>"` (zone `#DES_ZONE_*` tokens are retail).
- Loot: per-map `mp/levels/survival_preprocess/<map>.nut` is GENERATED by the engine: start the dedi with
  `+playlist survival +map <map> -survival_preprocess`; `PopulateSpecialZonesInternal` fills the zones from the
  ents and `ExportSurvivalScriptDataFileForMap` writes the file, then changelevels. Then add it to the rson and
  call `RunMySurvivalPreprocess()` in CodeCallback_MapInit. Never ship a stub (a preprocess with no zones = no
  loot). Without it, loot uses the runtime ent path. **The SDK dump guard used to refuse this `.nut` write**
  (only txt/csv/log/json under `scriptdump_`), so the export never landed -- unify `82e171345` allows exactly
  `tools/vscripts/mp/levels/survival_preprocess/[A-Za-z0-9_].nut`, dedi only, only with `-survival_preprocess`;
  dedi log line `[SCRIPT-GUARD] survival preprocess written to ...`.
- **Map particle effects (geysers, lava, snow/steam atmo) are NOT shipped by the main manifest** (`efct` is in
  SKIP) and S21 common has none of them (mu5: 92 of 95 fx.ent `effect_name`s missing; geysers =
  `P_env_geyser_idle_lrg{,_b,_t}`, which in S21 live only in hu's map pak). S30 map efct is v36 = v35 layout
  (list 0x188, same ops checksum). Pipeline (particle tools, not part of this kit):
  parse `efct.py <map .dec>` -> closure from the fx.ent names over `childEffects` (stop at S21-universe GUIDs)
  -> drop effects whose assetRefs resolve in neither the main manifest nor the MATCH-resident oracle (skip
  `mp_lobby` rows; mu5 dropped 29 + 1 lobby-only material) -> `EFCT_DROP_OPS=7 EFCT_ALLOW=.. EFCT_RESOLVABLE=..
  convert.py <out> <map .dec>` -> copy to `<ws>\extract\efct` -> `build_wraps.py --assemble-only` packs them
  into PERM (`map_effects()`; perm loads after the main pak so material refs resolve) -> gates
  verify_s30_pak / _probe_pak_alloc / _gate_efct_matnames + assetrefs vs main manifest + match oracle.
  mu5: 223 effects, all gates PASS. Geyser JUMP is script (common `GeyserInit`, 2 `geyser_jump` info_targets)
  and was never broken; the missing piece was the steam column.
